## Objective

Local delivery is an additive shipping method kind gated by geography: `local_delivery_zones` (method_id, pincodes JSON, fee_rule JSON) define deliverable areas; checkout validates the address pincode and hides the method entirely outside zones; delivery runs use staff assignment and the standard shipment machine with a manual carrier.

## Scope

**In scope:**

- `local_delivery_zones` entity + zone validation on checkout address selection
- `shipping_methods.kind` gains `local_delivery` with rate_table fees (fee_rule application)
- Delivery run flow: order → staff assignment → shipped/delivered via standard shipment machine (carrier `manual`)

**Out of scope:**

- Route batching/optimization — owned by Post-v1
- Carrier integrations for last-mile — owned by Deferred

## Acceptance criteria

1. **AC-T-2A09-02-1** — Zone gating holds: GIVEN an address whose pincode is outside every zone for the method WHEN shipping quotes compute THEN `local_delivery` is hidden (never selectable); inside-zone addresses see the method with the fee_rule fee applied.
2. **AC-T-2A09-02-2** — Delivery runs progress through the standard shipment state machine with carrier `manual`: staff assignment, mark shipped, mark delivered — no parallel shipment machine exists (architecture assertion).
3. **AC-T-2A09-02-3** — Zone pincodes + fee_rule validate on write: overlapping zones for one method resolve deterministically (documented precedence), and invalid fee_rule shapes reject with a named code.
4. **AC-T-2A09-02-4** — GIVEN a principal lacking `shipping:method:view` / `shipping:method:create` / `shipping:method:update` WHEN the corresponding request is issued THEN the platform returns 403 with envelope code `authorization_denied` and writes a denial audit record (negative path).
5. **AC-T-2A09-02-5** — Tenant isolation holds: every new table (`local_delivery_zones`) is covered by the `AssertTenantIsolation` matrix — cross-tenant reads return no rows and unresolvable tenant contexts fail closed (enforced by the [Tenant Isolation Suite (standing)](../../../19-testing/testing-strategy.md#tenant-isolation-suite-standing)).
6. **AC-T-2A09-02-6** — The module manifest declares every permission, event, and navigation entry introduced by this task; `platform:sync-permissions` and `module:list` reflect them, and every state change introduced writes an audit record (DoD items 3 + 5).
