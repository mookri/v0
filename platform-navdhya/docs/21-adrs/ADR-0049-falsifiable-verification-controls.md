# ADR-0049: Falsifiable Enforcement Controls & Sacred Ember Trust Surfaces

## Status
Accepted (2026-11-11)

## Context
Static `"Verified Pandits"` marketing labels and green success badges contradicted actual verification state and brand guidelines.

## Decision
Require falsifiable adversarial tests for every enforcement boundary across Phases 1–8 and render `<PartnerTrustBadge />` strictly from claim DTOs using Sacred Ember tokens (`#2C2033`, `#FFF7ED`, `#F16A24`, `#EFE3D3`, `#B74717`, `#2A2421`) with zero green tokens.
