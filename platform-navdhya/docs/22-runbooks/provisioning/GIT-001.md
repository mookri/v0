**Provider:** GitHub (organization: `navdhya`)
**Branch Strategy:** `main` (protected), feature branches `feat/*`, `fix/*`, `docs/*`

---

1. Navigate to https://github.com/organizations/navdhya/repositories/new
2. Repository name: `platform-navdhya`
3. Visibility: **Private**
4. Initialize with: **README** (we'll replace), **.gitignore** (Node + Laravel), **LICENSE** (MIT)
5. Default branch: `main`

## 6. Local Setup (Developer)

```bash
# Clone
git clone git@github.com:navdhya/platform-navdhya.git
cd platform-navdhya

# Configure git
git config user.name "Your Name"
git config user.email "you@navdhya.com"
git config commit.gpgsign true
git config gpg.program gpg

# Add upstream (if forked)
git remote add upstream git@github.com:navdhya/platform-navdhya.git
```
