# Support Case Lifecycle

NEW → TRIAGED → OPEN → (PENDING_CUSTOMER|PENDING_PARTNER|PENDING_INTERNAL) → RESOLVED → CLOSED; REOPENED → OPEN on customer reply. ESCALATED is an operational dimension. RESOLVED (outcome issued) ≠ CLOSED (workflow finished). Capability actions requested via gateways with idempotency + audit; capabilities emit authoritative events back to the timeline.
