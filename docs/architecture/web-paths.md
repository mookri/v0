# Web Application Path Ownership

| Path | Owner | Description |
| ---- | ----- | ----------- |
| `apps/web/app` | routes | Web route segments |
| `apps/web/components` | Web UI | React UI components |
| `apps/web/content` | Web content data | JSON registry and SEO markdown |
| `apps/web/domain` | transitional domain | Business logic (to be extracted) |
| `apps/web/application` | transitional application logic | Application logic (to be extracted) |
| `apps/web/infrastructure` | transitional adapters | External adapters (to be extracted) |
| `apps/web/public` | Web static assets | Images, fonts, favicons |
| `scripts` | repository tooling | Root-level CLI and maintenance scripts |
| `docs` | repository documentation | ADRs and architectural guidelines |
| `packages` | future shared capabilities | Shared workspaces (to be populated) |
