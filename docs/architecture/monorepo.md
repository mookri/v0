# Navdhya Monorepo

## Top-level boundaries

### apps/
Deployable product applications.

### packages/
Reusable capabilities and libraries.

### services/
Independently executable workloads.

### infrastructure/
Technology-specific infrastructure and external-system adapters.

### content/
Content/data, not application logic.

### tooling/
Developer and build tooling.

### tests/
Cross-application/system-level tests.

### docs/
Architecture, ADRs, standards and operational documentation.
