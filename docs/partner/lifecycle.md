# Partner Lifecycle

APPLIED → ONBOARDING → VERIFICATION_PENDING → VERIFIED → ACTIVE; SUSPENDED/PAUSED preserve history; TERMINATED ends work, never deletes history. Suspension ≠ identity deactivation (customer access continues). Readiness (services, areas, availability, agreement, documents) gates assignment, not status alone. Events: ApplicationSubmitted/Approved/Rejected/Suspended/Paused/Reactivated, ProfileUpdated, DocumentSubmitted/Verified/Expired → assignment, search, communication, analytics consumers.
