# Finance

Accounting truth: double-entry journal (debits = credits, immutable once posted, reversals not rewrites), invoices/credit-notes as documents (never recalculated), receivables with allocation, partner payables with hold/release, refunds with cumulative guards + idempotency, customer credits, reconciliation with exceptions, periods with close guards.
Never owns payment/booking/settlement execution; references them by ID. Minor-unit money only.
