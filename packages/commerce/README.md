# Commerce

Customer value relationships, never a balance blob. Owns: memberships (plan vs instance), entitlements (provenance + reservation lifecycle), credits (grant/reserve/consume/release with atomicity), wallets (entry-sourced projections), gift cards (hashed codes, partial redemption), loyalty (entry ledger, earn/redeem/reverse), referrals (qualification-gated).
Flows one way: commerce context → pricing → booking → payment → finance. Client-submitted amounts never trusted.
